# AIA Desktop — Autaza Inspection Analytics

Aplicação desktop em Python para registro, análise e rastreabilidade de inspeções industriais.

## Versão atualizada disponível

- **Versão atualizada em validação:** AIA Desktop **V1.3.0 RC**
- **Status:** Release Candidate — ainda não substitui a versão oficial estável.
- **Validação local:** 31/31 verificações aprovadas.

A V1.3.0 RC coloca D-I como indicador principal, atualiza o relatório PDF, adiciona rastreabilidade por linha em CSV/Excel e aprimora D-O com pareamento explícito por Correspondentes.

## Versão oficial estável

- **Última versão oficial:** AIA Desktop **V1.2.0**
- **Fechamento da release:** 10 de setembro de 2026

A V1.2.0 é mantida como baseline oficial; a V1.3.0 RC será promovida somente depois da validação de campo.

## Histórico preservado

Os pacotes de versões e materiais históricos são preservados no repositório. Nenhuma versão anterior é removida ou sobrescrita.

## Segurança e privacidade

O repositório não inclui credenciais, tokens, dados de inspeção, caches Python, builds nem executáveis.
